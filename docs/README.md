## 导出为 Word / PDF

### 方式一：Microsoft Word（推荐）

1. 打开 Word → **文件 → 打开**
2. 选择 `智能问数-产品与方案说明.md`
3. Word 会自动转换为可编辑文档
4. **文件 → 另存为** → 选择 `.docx` 或 **导出为 PDF**

### 方式二：VS Code / Cursor

1. 安装扩展「Markdown PDF」或「Markdown All in One」
2. 打开 `.md` 文件 → 右键 **Markdown: Export (pdf/docx)**

### 方式三：在线转换

将 `.md` 上传至支持 Markdown 导出的工具（如 Typora、语雀导入、飞书文档粘贴）后导出 Word/PDF。

### 方式四：打印标注页

在浏览器打开 `product-features-annotated.html` → **Ctrl+P** → 另存为 PDF，可作为附录插入方案。
