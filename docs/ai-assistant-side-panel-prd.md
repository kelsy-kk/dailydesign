## 二、版本目标

将智能问数从「独立全屏产品」升级为可嵌入任意宿主页面的**右侧贴边问数助理**。用户不再看到模型面板与大模型选择器，而是以**运营配置的业务场景**为入口完成问数；历史对话默认收起，回答区按 **390px 手机视口**重新排版，兼顾数据中台与业务系统两种嵌入形态。

### 2.1 范围增加

1. **双宿主嵌入**：支持数据中台（保留平台导航壳层）与业务系统（纯业务页 + 贴边助理）两种模式，通过 `embedMode` 配置切换。
2. **场景化冷启动**：首屏由运营后台按行业/租户下发场景卡片，替代「模型面板 + 元数据/分析并列引导」。
3. **贴边容器**：右侧贴边抽屉式面板（默认 390px，可拖拽调宽，最小 390px）+ 全局唤起按钮。

### 2.2 功能增加

1. 场景选择引导页（含场景图标、描述、示例问句）
2. 场景上下文内推荐问题（原「推荐问题」按场景过滤）
3. 历史对话抽屉（默认隐藏，可再次展开）
4. 手机宽回答页布局（气泡、折叠步骤、横向滚动表格）
5. 用户侧隐藏：模型面板 Tab、右侧资源树、LLM 下拉（已在 V1.0 全屏版实现，本版从贴边助理移除）

## 三、功能清单

### 3.1 贴边容器与宿主嵌入

#### 3.1.1 范围

- 覆盖：右侧贴边面板、唤起/关闭动效、宿主页面占位与遮罩
- 不包含：iframe 跨域通信协议（Phase 2）、小程序端

#### 3.1.2 展示权限

- 已授权问数能力的登录用户可见唤起按钮
- 无权限：不渲染 FAB，或点击提示「暂无问数权限」

#### 3.1.3 UI 交互点

a. 宿主页右下角 FAB「问数」唤起面板  
b. 面板默认 390px 宽，自右侧滑入，`z-index` 高于业务内容  
c. 点击遮罩或头部关闭按钮收起面板，不销毁会话状态  
d. 面板**左边缘拖拽把手**：左拖加宽、右拖缩小，宽度范围 390px ~ 65% 视口宽  
e. 聚焦把手后可用 ← / → 微调（Shift 加速）；宽度偏好本地持久化  
f. `embedMode=platform`：保留顶部数据中台导航；`embedMode=business`：仅业务内容区 + 助理  

#### 3.1.4 详情展示信息

| 元素 | 规格 |
|------|------|
| 面板宽 | 默认 390px；**支持左边缘拖拽调宽/缩小**，最小 390px，最大为视口宽 65% |
| 宽度记忆 | 拖拽结束后写入 `localStorage`，下次打开恢复 |
| 面板高 | `100vh - 宿主顶栏高度` 或 `100vh`（业务系统） |
| 动效 | 滑入 280ms ease-out（拖拽调宽时禁用宽度过渡） |
| 遮罩 | 半透明 `rgba(0,0,0,.25)`，业务系统可选无遮罩 |

| name | 展示名称，如「经营指标分析」 |

| 类型筛选（文档/PDF） | 移出用户路径，仅运营配置 |

### 3.3 历史对话（默认隐藏）

#### 3.3.1 范围

- 覆盖：面板内左侧滑出历史抽屉、收藏、新建对话
- 不包含：跨设备云同步（沿用 localStorage，与全屏版一致）

#### 3.3.2 展示权限

- 登录用户可查看自己的历史
- 默认**不展示**历史列表，仅保留头部「历史」图标入口

#### 3.3.3 UI 交互点

a. 面板头部「历史」图标 → 从左侧滑出 300px 历史抽屉  
b. 抽屉内：新建对话、历史列表、收藏（结构同全屏版侧栏）  
c. 点击历史项 → 加载会话并关闭抽屉  
d. 点击抽屉外或关闭 → 收起抽屉，回到当前对话  
e. 新建对话 → 若当前无消息则回场景引导页；有消息则新建并回场景引导页  

#### 3.1.4 详情展示信息

- 历史项：标题（首问摘要）、更新时间（相对时间）
- 空态：「暂无历史对话，选个场景开始问数吧」

#### 3.4.3 UI 交互点

a. 用户气泡 `max-width: 88%`，右对齐  
b. 回答步骤默认展示「结论区」（图表/表格/KPI）；**不展示 SQL 及语义推理中的 SQL 代码**  
c. 可选展开「数据解释」：仅展示业务模型/数据集/指标/维度映射表  
d. 数据表格横向滚动，表头固定  
e. 图表高度限制 200px，支持图表/表格切换  
f. 引导面板操作按钮改为纵向全宽按钮（原「打开模型面板」改为「换个场景」或示例问句）  

#### 3.4.4 详情展示信息

| 模块 | 手机宽适配要点 |
|------|----------------|
| SQL / 语义推理 | **用户侧完全不展示**（含 SQL 代码、修正 SQL、语义推理叙事中的 SQL） |
| 数据解释（可选） | 点击「查看数据解释」展开模型/指标/维度映射表，无 SQL |
| KPI 卡片 | 2 列网格 → 单列堆叠 |
| 对比表 | `overflow-x: auto` |
| 元数据卡片 | 单列，字号 13px |
| 相关推荐 | 最多展示 3 条 |
| 输入区 | 单行起，最多 3 行，无模型下拉 |
