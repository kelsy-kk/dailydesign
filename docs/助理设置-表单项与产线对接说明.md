# 智能问数 · 助理设置表单项与产线对接说明

**文档版本**：V1.0  
**日期**：2026-07-28  
**原型入口**：`assistant-panel.html` / `index.html` → 系统设置 → **助理设置**  
**相关实现**：`assistant-widget.js` / `assistant-widget.css`（宿主内嵌助理）、`index.html`（助理设置 + 图标显隐）  

**使用约定**：默认无助理图标；在「助理设置」中新建并**启用**后，右侧出现图标，打开面板内容与配置项一致。

---

## 1. 文档目的与阅读对象

| 读者 | 用途 |
|------|------|
| 产品 | 对齐助理配置能力边界与产线隔离逻辑 |
| 产线 / 业务对接 | 明确每项配置由谁填、何时填、对运行时的影响 |
| 研发 / 实施 | 字段语义、校验、默认值与接口落点 |

**一句话**：助理设置以「助理列表」管理已配置的问数助理实例；点进编辑页后定义「某个产线入口下的问数助理」——它能用哪些业务模型、默认怎么表现、如何被嵌入调用。

## 2. 对象关系（对接总逻辑）

```text
产线/产品模块（如施工、造价）
  └─ 问数助理实例（本页配置的主体）
        ├─ 所属产线名称 + CODE（归属，支持手动输入）
        ├─ 可用业务模型列表（问数元数据范围）★
        ├─ 默认模型 / 场景 / 大模型等体验策略
        └─ 嵌入方式 + 调用凭证
              │
用户从产线打开助理 ──► 带入助理编码 + 登录租户/组织
              │
问数引擎 ──► 仅在「已绑定且已发布」的模型内做语义解析与查数
```

### 2.1 产线对接原则

1. **一个产线至少一个助理实例**（也可按场景拆多个，如「经营助理」「台账助理」）。
2. **模型绑定是隔离核心**：未绑定的模型对用户不可见、不可解析；禁止配置为空却启用后回退「全量模型」。
3. **租户 / 组织一般不手填**：从用户登录态继承；助理配置声明「沿用平台数据权限」。
4. **建模与挂载分权**：建模员负责把模型做到「已发布」；产线管理员在本页决定挂哪些模型到助理。

### 2.2 配置角色（权限摘要）

| 角色 | 本页能力 |
|------|----------|
| 产线管理员 | 编辑本产线助理、绑模型、启用/停用、体验策略 |
| 平台超管 | 跨产线查看/调整；凭证与嵌入高级项 |
| 业务建模员 | 通常不改本页；保证模型发布状态可供勾选 |
| 实施 / 开发 | 查看/轮换 AppKey；确认嵌入方式 |
| 普通业务用户 | 不可见配置页，只使用助理 |

## 3. 分区与表单项明细

进入 **助理设置** 先展示 **已配置问数助理列表**（可搜索、新建、编辑、启停）；点「新建 / 编辑」进入下方表单分区。

### 3.0 助理列表（默认视图）

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstListView` / `asstTableBody` / `asstSearchInput` / `asstCreateBtn` |
| **列表列** | 序号、助理名称、助理编码、产线/产品、产品 CODE、启用状态、绑定模型、更新时间、操作 |
| **操作** | 编辑（进入表单）、启用/停用（列表快捷切换；无绑定模型不可启用） |
| **产线对接** | 列表即权限域下已配置的问数助理目录；可按产品 CODE 过滤查看本产线助理 |

下列「原型控件 ID」与表单一致，便于联调对照。

### 3.1 基本信息

#### 3.1.1 助理名称（必填）

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstName` |
| **作用** | 用户侧与管理侧展示名，如「施工问数助理」。 |
| **产线对接** | 产线命名规范建议：`{产线}问数助理`；嵌入页标题、历史会话归属展示可复用。 |
| **原型行为** | 文本输入；保存时非空校验。 |
| **空/错** | 未填不可保存。 |

#### 3.1.2 助理编码（必填，自动生成）

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstCode` |
| **作用** | 系统唯一标识，嵌入 SDK、网关鉴权、配置拉取的主键。 |
| **生成逻辑** | **根据助理名称自动生成**，不可手改。英文/数字转 slug（`asst-xxx`）；纯中文等用稳定哈希（`asst-<36进制>`）；与已有编码冲突时自动追加 `-2`、`-3`… |
| **产线对接** | 产线研发在嵌入代码中传入此编码以加载对应配置；名称变更会导致编码重算，需同步嵌入方。 |
| **原型行为** | 只读；随「助理名称」输入实时更新；保存时非空校验。 |

#### 3.1.3 所属产线 / 产品名称（必填）

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstProductName` |
| **作用** | 助理所属产线/产品的展示名称，如「施工」「造价」。 |
| **产线对接** | **支持用户手动输入**，与产线主数据名称对齐；用于管理列表展示、运营归属识别。 |
| **原型行为** | 文本输入；保存时非空校验。 |
| **空/错** | 未填不可保存。 |

#### 3.1.4 所属产线 / 产品 CODE（必填）

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstProductCode` |
| **作用** | 产线/产品系统唯一编码，供权限域、模型过滤、嵌入对接使用。 |
| **产线对接** | **支持用户手动输入**（如 `construction`）；与产线主数据 CODE 对齐。嵌入与配置拉取按 CODE 做归属匹配，而非仅按中文名。 |
| **原型行为** | 文本输入；保存时非空校验。 |
| **注意** | 创建后建议勿随意变更；变更等于换归属域，需重算可选模型并同步嵌入方。 |

#### 3.1.5 启用状态（必填）

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstEnabled` |
| **作用** | 控制该助理是否可被终端打开并问数。 |
| **产线对接** | `启用`：嵌入入口可用；`停用`：入口可隐藏或打开后提示「助理未启用」。上线验收以「启用 + 模型绑定合法」为准。 |
| **原型行为** | 停用 / 启用；若勾选模型为空仍选启用，保存时拦截并强制倾向停用逻辑提示。 |
| **规则** | **无可用模型时不得启用**（产品硬规则）。 |

#### 3.1.6 说明（可选）

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstDesc` |
| **作用** | 给管理员的备注（范围说明、对接人、注意事项），不对终端用户展示。 |
| **产线对接** | 可写「仅施工域合同/项目模型」「对接人 XXX」等，便于多产线运营交接。 |

### 3.2 业务模型绑定（核心）

> 本区是产线隔离的产品落点：助理可见元数据 = 此处勾选的已发布模型集合。

#### 3.2.1 可用业务模型（必填，至少 1 个）

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstModelBindPanel` / `asstModelList` / `name=asstModels` |
| **作用** | 定义问数引擎可检索的业务模型集合（数据集、维度、指标、口径等元数据来源）。 |
| **分类 Tab** | **域模型** / **基础模型** / **PML业务对象**（`data-model-tab`）；Tab 角标显示该分类已选数量。 |
| **搜索** | `asstModelSearch`：在当前 Tab 内按名称 / 编码 / 说明过滤；数据量大时避免一次铺开。 |
| **产线对接** | 列表数据源 =「本产线有权 + 已发布」的对应分类对象。草稿不可绑（`disabled`）。跨 Tab 勾选结果合并为同一绑定集合。 |
| **原型行为** | 多选卡片；勾选状态跨 Tab 保留；驱动「默认业务模型」下拉（选项标注所属分类）。 |
| **运行时** | 语义解析、推荐问句、SQL/图表生成均不得超出该集合。 |
| **校验** | 零勾选 → 保存失败，提示不可启用。 |

**原型示例（演示数据，各类约 10 条便于验证搜索）**

| 分类 | 示例 | 状态 |
|------|------|------|
| 域模型 | 合同经营、项目执行、物资库存、造价测算… | 已发布；含草稿项演示不可绑 |
| 基础模型 | 组织、用户、项目主数据、物料、供应商… | 已发布 |
| PML业务对象 | 合同对象、项目对象、WBS、工程量清单… | 已发布；含草稿项 |

#### 3.2.2 默认业务模型（必填）

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstDefaultModel` |
| **作用** | 首问、歧义消解、未指定模型时的优先语义空间。 |
| **产线对接** | 须为「可用业务模型」子集中的一项；产线按主业务域指定（如施工优先「合同经营」）。 |
| **原型行为** | 下拉仅列出已勾选模型；取消勾选后若默认失效需重选。 |
| **校验** | 默认值不在已选列表 → 保存失败。 |

#### 3.2.3 模型切换

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstModelSwitch` |
| **作用** | 是否允许终端用户在助理内切换当前业务模型。 |
| **选项** | `允许用户在助理内切换` / `不允许切换（固定默认模型）` |
| **产线对接** | 单域产线可关切换，降低误选；多域（合同+项目+库存）建议开，并在 UI 展示当前模型名。 |
| **运行时** | 关闭时：隐藏切换器，全程使用默认模型；开启时：仅可在「可用列表」内切换。 |

#### 3.2.4 绑定生效策略

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstBindEffect` |
| **作用** | 管理员改绑定后，对已有会话何时生效。 |
| **选项** | `下次会话生效`（推荐） / `立即生效` |
| **产线对接** | 默认「下次会话」可避免用户对话中途语义世界突变；强管控变更可选立即生效并提示刷新。 |
| **影响** | 改绑可能导致历史问句、收藏问法不再适用，需在发布说明中告知产线。 |

### 3.3 运行上下文

#### 3.3.1 租户

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstTenant` |
| **作用** | 标识数据与账号的租户边界。 |
| **产线对接** | **通常只读**，由登录态 / 嵌入方 token 带入，不在助理配置里手写租户号。配置页展示「当前登录租户」便于实施核对。 |
| **运行时** | 与平台租户隔离一致；问数查数受租户数据权限约束。 |

#### 3.3.2 组织

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstOrg` |
| **作用** | 租户内组织边界（部门/项目部等）。 |
| **产线对接** | 默认同登录组织；集团型产线若需「组织范围」扩展，属后续能力，MVP 只读展示。 |
| **原则** | 助理**不另造一套数据权限**，声明沿用平台权限模型。 |

### 3.4 问数体验

#### 3.4.2 默认大模型

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstLlm` |

| **原型选项** | AceGPT（默认）/ DeepSeek / gpt-4o |

| **产线对接** | 推荐问句落在「当前助理绑定模型」语义内，从已发布 SQL 示例中取数。 |

#### 3.4.4 欢迎语文案

#### 3.4.5 推荐「换一批」

### 3.5 语义增强

#### 3.5.1 使用模型下术语

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstUseTerms` |
| **作用** | 是否加载绑定模型（域）下的术语表，辅助 LLM 理解业务同义词与口径。 |
| **产线对接** | 术语应在模型归属域维护（设置页「术语配置」）；助理侧只做开关，避免再建一套全局术语导致串口径。 |
| **建议** | 默认开启。 |

#### 3.5.2 使用模型下 SQL 示例

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstUseSqlExamples` |
| **作用** | 是否使用绑定模型相关的「问题-SQL」示例，提升生成 SQL 贴合度。 |
| **产线对接** | 示例库（设置页「SQL 示例库」）应按模型/业务域隔离；仅注入本助理可用模型下的示例。 |
| **建议** | 默认开启。 |

#### 3.5.3 自定义提示词（本助理补充）

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstCustomPrompt` |
| **作用** | 本助理级补充指令（语气、单位展示、行业偏好等）。 |
| **产线对接** | **补充而非替代**模型域 / 平台提示词；产线可写「金额默认万元」「优先施工口径」等。 |
| **注意** | 过长或与模型域提示词冲突时，需运营规范与优先级约定（平台 < 模型域 < 助理补充，或相反——上线前需技术确认）。 |

### 3.6 嵌入与调用

#### 3.6.1 嵌入方式

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstEmbedMode` |
| **作用** | 助理在宿主中的呈现形态。 |
| **选项** | 贴边助理 / 页面内嵌 / 独立页 |
| **产线对接** | 与产线前端接入方式一致；贴边对应 `assistant-panel` 类体验，内嵌/独立页需产线提供容器路由。 |
| **实施** | 编码 + 嵌入方式 + 宿主域名白名单（正式环境字段，原型未展开）。 |

#### 3.6.2 默认主题

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstTheme` |
| **作用** | 打开助理时的默认主题（浅色 / 深蓝）。 |
| **产线对接** | 可与产线品牌色规范对齐；用户仍可在助理内自行切换（若产品保留主题按钮）。 |

#### 3.6.3 调用凭证 AppKey

| 项 | 说明 |
|----|------|
| **原型 ID** | `asstAppKey` / `asstAppKeyDecryptBtn` / `asstAppKeyPreview` |
| **作用** | 嵌入方调用配置与问数服务的凭证标识。 |
| **生成逻辑** | 由 **产品 CODE + 产品名称 + 助理编码** 按固定密钥 XOR 后 Base64URL 编码，格式 `ak_<密文>`；修改产线名称/CODE/助理编码时自动重算。 |
| **解密** | 「解密预览」可还原出产品 CODE、产品名称、助理编码，便于实施核对归属（原型演示可逆算法；正式环境应使用平台签发 + 服务端验签）。 |
| **产线对接** | 嵌入方携带 AppKey；服务端解密/验签后匹配助理与产线归属域。 |
| **权限** | 仅实施/开发或超管可查看完整密钥与解密预览。 |

## 4. 与设置页其他 Tab 的关系

| 设置 Tab | 与助理设置的关系 |
|----------|------------------|
| 术语配置 | 按模型/业务域维护；助理「使用模型下术语」开启时注入 |
| SQL 示例库 | 按问题-SQL 与业务域维护；助理「使用模型下 SQL 示例」开启时注入，且应过滤到绑定模型 |
| 自定义提示词 | 平台/域级指令库；助理「自定义提示词」为实例级补充 |
| **助理设置** | 产线实例总装：绑哪些模型 + 体验 + 嵌入 |

## 5. 产线对接流程（建议）

```text
1. 建模员在业务建模中完成模型 → 发布
2. 产线管理员打开「助理设置」→ 新建助理（或编辑已有）
3. 填写所属产线名称与 CODE → 勾选可用已发布模型 → 设默认模型
4. 配置场景、推荐、提示词等体验项
5. 实施配置嵌入方式与 AppKey，产线前端传入 asstCode
6. 启用助理 → 联调：仅能问到绑定模型内指标/维度
7. 验收：他产线模型不可见；未发布模型不可绑；无模型不可启用
```

### 5.1 嵌入方最小对接参数（逻辑）

| 参数 | 来源 | 说明 |
|------|------|------|
| `assistantCode` | 本页「助理编码」 | 拉取配置 |
| `tenantId` / `orgId` | 登录态 | 上下文与数据权限 |
| `userToken` | 登录态 | 鉴权 |
| `theme`（可选） | 本页默认主题或宿主覆盖 | UI |

服务端根据 `assistantCode` 返回：可用模型 ID 列表、默认模型、场景、LLM、开关项等；**禁止**客户端自行指定任意模型 ID 越权。

## 6. 校验与运行时规则汇总

| 规则 | 说明 |
|------|------|
| R1 | 可用模型数量 ≥ 1 才允许「启用」 |
| R2 | 默认模型必须属于可用模型 |
| R3 | 仅「已发布」且有权限的模型可勾选 |
| R4 | 问数检索范围 = 可用模型 ∩ 用户数据权限 |
| R5 | 无助理上下文时，不得默认开放全平台模型 |
| R6 | 术语 / SQL 示例 / 推荐问句均不得突破绑定模型语义 |
| R7 | 改绑定按「生效策略」作用于会话 |

## 7. 原型与正式版差异（对接时注意）

| 点 | 原型 | 正式版建议 |
|----|------|------------|
| 模型列表 | 写死 4 条演示数据 | 接口按产线+权限拉取 |
| 租户/组织 | 只读文案 | 展示真实名称，仍不手填 |
| AppKey | 打码只读 | 权限控制下的查看/轮换 |
| 保存 | 前端提示，无持久化后端 | 存配置中心 / 问数配置服务 |
| 重置 | 恢复示例 DOM | 恢复已保存版本或删除 |
| 产线枚举 | 固定 4 个 | 对接产线主数据 |

## 8. 验收清单（产线联调）

- [ ] 产线 A 助理仅能检索其勾选模型；看不到产线 B 模型  
- [ ] 取消全部模型后无法保持「启用」保存成功  
- [ ] 默认模型随勾选变化，非法默认无法保存  
- [ ] 关闭「模型切换」后前端无切换入口  
- [ ] 术语/SQL 示例开关关闭后，问数链路不再注入对应资源  
- [ ] 嵌入方只传 `assistantCode` + 登录态即可拉齐配置  
- [ ] 停用后入口不可问数或明确提示
