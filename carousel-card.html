数据链路与接口约定
数据源 当前仅开放 API 接口；数据集、本地上传置灰暂未开放（配置面板与逻辑已就绪，开放时移除禁用即可）。
请求配置 请求地址 + 请求方式（GET / POST）+ 参数列表。参数支持「+ 添加」逐个配置，或批量粘贴 a=1&b=2 / JSON 自动解析成参数行（解析后统一为控制器，需再为每个参数选择控制器）。
参数取值 取值方式仅「控制器」一种（默认即控制器）。参数值绑定仪表板控制器的名称，请求时取控制器的当前值，值为空时该参数不传。可用控制器（模拟）：部门下拉筛选框、时间筛选框、项目下拉筛选框、期间筛选框。
响应字段选择 按后端返回的字段名配置：媒体地址、封面地址必填（未填写不发请求并提示），标题选填（留空自动识别 title / name / fileName）。媒体类型按地址扩展名自动判断，无需配置。
标题浮层联动 未配置「标题」响应字段时，「显示标题浮层」开关自动关闭并禁用，提示去数据源配置；配置后解锁可开启。
返回结构 兼容三种：数组、{ data: [...] }、{ data: { list: [...], total: 37 } }（也识别 items / records / rows）。
字段兼容 响应字段选择显式指定的字段优先；未指定时按兼容列表识别 —— 地址 src / url / videoUrl / videoPath / path / fileUrl，封面 poster / cover / coverUrl / image / thumbnail。
失败降级 接口失败时展示错误态并提供「重试」；必填响应字段（媒体地址 / 封面地址）未配置时拦截请求并引导配置。

已确认

  1. 数据源开放范围：当前仅 API 接口，数据集 / 本地上传暂未开放。
  2. 参数取值：仅「控制器」一种，参数值绑定控制器名称，取控制器当前值，空值不传。
  3. 响应字段：媒体地址、封面地址必填；标题选填；媒体类型按地址扩展名自动判断。
  4. 媒体字段：fileUrl 可直连、视频必须带 coverUrl（封面地址必填即为此服务）。
