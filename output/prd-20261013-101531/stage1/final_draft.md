## 一、背景与目标

### 1.1 背景
建模中心「定义语义」下已有模型、指标、文档、权限等资产，但业务口语（合同额、GMV、签约日期）散落在字段别名、指标描述与个人沟通中，同一概念多处定义、口径不一致。术语中心作为定义语义下的独立模块（与指标语义、文档中心、权限中心并列），承担「标准词汇统一沉淀 + 向下挂载模型字段 + 向上支撑指标口径」的职责。

### 1.2 要解决的问题
1. 同一业务概念在模型字段、指标、报表中的叫法与含义不一致；
2. 字段缺少标准业务定义，字段 → 指标的口径链路不可信；
3. 术语没有统一的上线治理，随意引用导致脏语义扩散。

### 1.3 成功指标（建议口径，估算）
| 指标 | 口径 | 目标 |
|---|---|---|
| 字段挂载率 | 已挂载术语的字段数 ÷ 生效模型下字段总数 | 首期 ≥ 30% |
| 术语引用度 | 被指标引用的术语数 ÷ 已上线术语数 | 首期 ≥ 50% |
| 重名收敛 | 同工程同域内重名术语对数 | 不新增 |

## 二、名词与术语定义

| 名词 | 定义 |
|---|---|
| 术语库（Glossary） | 术语的容器，含名称、描述、创建人、创建时间，绑定唯一数据域（1 库 : 1 域） |
| 术语（Term） | 一条标准业务词汇：名称、同义词、描述、所属数据域（多选）、生效模型（可为空）、上线状态 |
| 数据域 | 业务分类边界（如收入管理、成本管理），同时是权限过滤维度 |
| 生效模型 | 术语适用的模型集合，必须是所属数据域下模型的子集；为空 = 对该域下全部模型生效 |
| 挂载 | 建立「模型.字段 ↔ 术语」的引用关系，使字段获得标准业务定义 |
| 上线 | 术语的可用状态；只有已上线术语才能被字段推荐挂载或被指标引用 |
| 词根 | 物理建模侧字段命名规范的最小语素，术语是其上游输入 |

## 三、需求范围

**包含（本期）**：术语库管理（新建/编辑/删除/切换）；术语创建、编辑、删除；上线/下线；批量移动域、批量上下线、批量删除；CSV 导入（四步向导）/导出/模板下载；列表查询筛选与分页；术语详情与引用反查；字段自动推荐挂载与批量挂载/解绑；指标引用术语；关系图谱；按数据域 + 工程的权限过滤；空状态与引导。

**不包含（本期不做）**：术语父子层级与关联术语（后续版本）；上线审批流与活动信息流（页签已预留、暂隐藏）；术语版本化与变更对比；软删除回收站；词根同步的自动执行（本期仅保留入口，同步流程另行立项）；多语言术语。

## 四、方案选型说明

| 决策点 | 选择 | 理由 | 放弃项 |
|---|---|---|---|
| 状态模型 | 上线/下线二态 | 治理链路轻、用户理解成本低，先跑通挂载闭环 | 草稿/审批/废弃多态审批流 |
| 重名治理 | 域内联想提醒 + 确认即覆盖 | 收敛优先，避免新建被重名阻塞 | 强拦截重名 |
| 删除策略 | 硬删除 + 引用量强制提示 | 引用关系自然失效，实现简单可追溯 | 软删回收站 |
| 字段匹配 | 精确命中 + 描述相似度（≥0.45）两档推荐 | 无算法依赖、可解释、可降级为人工挂载 | 向量语义匹配 |

## 五、用户角色与使用场景

| 角色 | 描述 | 核心场景 |
|---|---|---|
| 术语管理员 | 数据治理人员 | 建术语库、批量导入术语、上线治理、移动域整理 |
| 业务建模人员 | 模型/指标建设者 | 建模型字段时采纳术语推荐挂载；建指标时引用术语 |
| 业务查询用户 | 报表/问数消费者 | 通过术语详情、关系图谱理解字段与指标口径 |
| 系统管理员 | 权限配置者 | 按数据域配置可见/可操作范围 |

主流程场景：术语管理员在「交易业务术语库」导入 50 条术语 → 上线 → 建模人员进入模型字段设置，系统自动推荐挂载 → 采纳后字段获得标准定义 → 指标编辑时从已上线术语中多选引用 → 通过关系图谱查看「模型 → 字段 → 术语 → 指标」全景。

## 六、功能需求

### FR-01 术语库管理
- **规则**：新建/编辑抽屉含名称（必填，≤50 字）、描述（选填，≤300 字）、所属数据域（必填，单选，基于该域管理和展示）；术语库列表按域统计术语数；删除库后自动切换到第一个库。
- **验收**：
  - Given 未填名称，When 点保存，Then 提示「请填写术语库名称」并聚焦名称框；
  - Given 未选数据域，When 点保存，Then 提示「请选择所属数据域」；
  - Given 当前库绑定「收入管理」，When 打开新建术语表单，Then 数据域反显「收入管理」并提示「ⓘ 已默认继承当前术语库「xx」的数据域「收入管理」，可按需修改」。

### FR-02 创建术语
- **规则**：表单含术语名称（必填）、数据域（必填多选，支持搜索与全选）、生效模型（联动：未选域提示「请先选择数据域」；仅列出所选域下模型，域变化自动裁剪越界模型；支持搜索与全选）、同义词（逗号/顿号分隔）、描述。重名在名称失焦或域变化时实时联想：按「所选数据域」查重，提示「⚠ 重名提醒：「xx域」数据域已存在同名术语：a、b，请调整名称或数据域，确定则直接覆盖。」；保存时再次确认，**确认后覆盖保存，不拦截**。保存成功后新术语置顶、默认未上线，提示「已创建术语：xx（默认未上线，上线后可供挂载）」。
- **验收**：
  - Given 名称为空，When 保存，Then 提示「请填写术语名称」；
  - Given 未选数据域，When 保存，Then 提示「请至少选择一个数据域」；
  - Given 所选域已存在同名术语，When 确认覆盖保存，Then 保存成功且原同名术语保留（两条并存）；
  - Given 选中「收入管理」，When 展开生效模型下拉，Then 仅显示收入管理域下模型；When 追加选择「成本管理」后再移除「成本管理」，Then 成本管理下已选模型被自动移除。

### FR-03 编辑术语
- **规则**：回填全部字段；重名校验排除自身；修改域/生效模型后引用不丢——已挂载字段按最新生效范围重新过滤展示，记录保留，改回即恢复。
- **验收**：Given 术语挂载于模型 A 字段 f1，When 将生效模型改为仅模型 B 并保存，Then 详情/图谱中不再展示 f1 挂载；When 改回模型 A，Then f1 挂载恢复展示。

### FR-04 删除术语
- **规则**：单条删除确认文案「确定删除术语「xx」吗？该术语已挂载 N 个指标、M 个字段，删除后指标/字段上的对应挂载引用将一并失效。」（N/M 为实时引用统计，忽略项不计入字段数）；删除为硬删除，引用级联失效。
- **验收**：Given 术语被 2 个指标、3 个字段引用，When 点删除，Then 弹窗显示「已挂载 2 个指标、3 个字段」；确认后列表移除且指标/字段侧引用失效。

### FR-05 上线 / 下线
- **规则**：行内「上线/下线」即时切换并反馈；**上线是挂载前提**——未上线术语不进入字段推荐匹配、不进入指标候选池；下线不解除存量挂载，仅冻结新增。
- **验收**：
  - Given 未上线术语与某字段精确同名，When 进入该模型字段设置，Then 不出现该术语推荐；
  - Given 已上线并被指标引用的术语，When 下线，Then 指标上的引用保留；When 再编辑指标，Then 候选池中不出现该术语。

### FR-06 批量操作
| 操作 | 规则 |
|---|---|
| 批量移动域 | 选择目标域（多选）→ 术语数据域**整体替换**→ 自动裁剪越界生效模型 → 执行前重名预检并提示「确定则直接覆盖」 |
| 批量上下线 | 直接批量切换，反馈「已将 N 条术语上线/下线」 |
| 批量删除 | 先汇总所选术语引用统计，确认后一并删除 |
- **验收**：Given 勾选 3 条含生效模型的术语，When 批量移动到不含其模型的域，Then 三条术语生效模型被清空/裁剪，数据域替换为新域。

### FR-07 列表查询与筛选
- **规则**：搜索覆盖名称/同义词/描述/数据域/工程/生效模型，命中关键词高亮；表头「数据域」「上线状态」筛选；分页每页 15 条，筛选条件变化自动回到第 1 页；全选仅作用于当前筛选结果，取消勾选与半选状态联动；顶部统计显示筛选后总数。
- **验收**：Given 第 3 页且输入新关键词，When 搜索，Then 回到第 1 页；Given 勾选后修改筛选使已勾选行不可见，Then 该行自动移出选中集。

### FR-08 批量导入（四步向导）
1. **上传**：CSV 文件，自动识别 UTF-8/GBK/GB18030 编码；表头必须含「术语名称、同义词、术语描述」（支持常见别名映射：名称→术语名称、描述→术语描述等）；可下载模板（表头 + 一行示例）、使用示例文件；文件自动归档到文档中心；缺列报错「已读取「xx」，但缺少列：…」；仅有表头报错「文件只有表头，没有数据行」。
2. **设置**：目标数据域多选（默认继承当前术语库域并提示，可改）；导入模式三选一：`新增`（域内重名行报错不可覆盖）、`新增或更新`（域内重名行标记「更新」）、`覆盖`（**先清空所选目标域下全部术语**再导入）。
3. **预览**：逐行校验——名称为空、CSV 内名称重复、新增模式下域内已存在；汇总「共 N 行：可新增 x，将更新 y，失败 z」，失败行标红并给原因。
4. **确认导入**：合法行执行；更新时域为**合并**语义（保留原域并集新域）；新增术语默认未上线；反馈新增/更新条数。
- **验收**：
  - Given GBK 编码 CSV，When 上传，Then 正确解析中文；
  - Given 新增模式 + 域内已存在同名，When 预览，Then 该行失败并提示「数据域「xx」下术语已存在（新增模式不可覆盖）」；
  - Given 覆盖模式，When 确认导入，Then 所选域下原有术语全部移除，仅保留本次导入内容。

### FR-09 导出与模板
- **规则**：导出按当前筛选结果生成 CSV（含 BOM，兼容 Excel），文件名 `术语导出_yyyymmdd.csv`，反馈「已导出 N 条术语」；空结果提示「暂无可导出的术语」。模板下载为表头 + 示例行。
- **验收**：Given 筛选「未上线」后导出，Then 文件仅含未上线术语。

### FR-10 术语详情与引用反查
- **规则**：详情抽屉 = 基本信息（名称/数据域/生效模型/所属工程/同义词/描述/状态）+ 关联指标清单 + 关联字段清单；清单可点击直达对应指标/字段；引用计数与删除确认共用同一口径。
- **验收**：Given 术语被指标 M1 引用，When 点详情中 M1，Then 关闭抽屉并打开 M1 详情。

### FR-11 字段挂载（推荐 + 手动）
- **推荐匹配**（进入模型字段设置时触发，候选范围 = 已上线 + 对该字段所在模型生效的术语）：
  - **精确命中**：字段英文标识或中文别名（忽略大小写与空白）等于术语名称或任一同义词；
  - **推荐命中**：字段描述与术语描述相似度 ≥ 0.45（中英文兼容的 token 二元组重叠算法）；精确命中排序在前。
- **确认/忽略**：采纳写入挂载关系；忽略写入忽略清单不再打扰、可恢复；忽略不计入引用统计。
- **批量挂载抽屉**：勾选模型字段 → 检索术语（名称/同义词，仅已上线）→ 「挂载所选术语」/「解绑所选术语」。
- **验收**：
  - Given 字段别名「合同金额」、术语「合同额」同义词含「合同金额」，When 匹配，Then 精确命中；
  - Given 字段描述与术语描述相似度 0.30，Then 不产生推荐；
  - Given 忽略某推荐，When 再次进入字段设置，Then 不再提示；恢复忽略后重新出现。

### FR-12 指标引用术语
- **规则**：指标编辑支持引用多个术语；候选池 = 已上线且同工程的术语；引用关系在指标详情展示并可跳转。
- **验收**：Given 候选池含未上线术语，Then 不展示。

### FR-13 关系图谱
- **规则**：术语库内页签切换；四类节点（模型/字段/术语/指标）全景展示，边为「模型→术语（生效）、字段→术语（挂载）、术语→指标（引用）」；顶部统计条实时显示四类节点数量；交互：悬停高亮一度关联、点击锁定聚焦、点击空白取消、滚轮/按钮缩放、拖拽平移；库内无术语显示空态引导「先在「术语」页签创建或导入」；切换术语库自动重渲染。
- **验收**：Given 空库，When 切到图谱页签，Then 显示空态引导文案。

### FR-14 权限过滤
- **规则**：术语列表按数据域 + 工程双重过滤——用户对术语所有所属域均无访问权时不可见；指标候选池按工程过滤。
- **验收**：Given 用户仅有「收入管理」域权限，When 打开术语列表，Then 仅见所属域含「收入管理」的术语。

### FR-15 空状态与引导
- **规则**：库内无术语 → 隐藏列表、展示引导卡片「添加第一个术语」+「+ 新术语」按钮（等效创建入口）；筛选后无结果 → 列表显示「暂无术语，点击「创建」或「导入」添加」。

## 八、业务流程与状态流转

**术语状态机**：
```
未上线（新建/导入默认） ──上线──▶ 已上线 ──下线──▶ 未上线
        │                            │
        └────────── 删除 ◀───────────┘（任意状态可删，删除前强制提示引用量）
```
- 未上线：可见、可编辑、可删除；**不可被字段推荐、不可被指标引用**。
- 已上线：进入字段推荐池与指标候选池；下线仅冻结新增挂载，存量引用保留。

**导入执行流**：上传校验 →（域继承）→ 模式选择 → 逐行校验预览 → 执行（覆盖模式先清空所选域）→ 归档 + 反馈。

**变更传播**：
- 改域/模型 → 越界生效模型自动裁剪 → 原挂载在新范围外时图谱/详情不再展示（记录保留）；
- 改名称/同义词/描述 → 影响字段推荐命中面（精确与推荐两档）；
- 上线/下线 → 新增挂载开关（见 FR-05）。

## 十、权限与安全

- **数据权限**：以数据域为第一边界、工程为第二边界；列表读取时按域过滤（用户对所有所属域无权限的术语不可见）。
- **操作权限**（规划，随权限中心迭代）：术语管理员可增删改/上线/导入；业务建模人员仅可采纳挂载与引用；查询用户只读。
- **安全要求**：删除与覆盖导入二次确认；输出转义防 XSS；导入文件类型限制 CSV。

## 十一、异常处理清单

| # | 场景 | 处理 |
|---|---|---|
| 1 | 创建未填名称 / 未选域 | 阻断保存，提示并聚焦对应控件 |
| 2 | 重名 | 联想提醒 + 保存时确认覆盖，不硬拦截 |
| 3 | 导入缺列 / 只有表头 / 读取失败 | 明确报错（缺哪些列 / 无数据行 / 请重新选择），不进入下一步 |
| 4 | 导入全部行失败 | 提示「没有可导入的合法行」，可返回预览查看原因 |
| 5 | 覆盖导入误操作 | 步骤 3 预览明示覆盖范围，步骤 4 确认后执行；文件已归档可追溯 |
| 6 | 删除被引用术语 | 强制提示引用量（N 指标 / M 字段），确认后级联失效 |
| 7 | 域切换导致生效模型越界 | 自动裁剪，无需用户手动处理 |
| 8 | 筛选/翻页边界 | 无结果空态；页码越界自动收敛到有效页；筛选变更重置页码 |
| 9 | 图谱无数据 | 空态引导文案 |
| 10 | 弹层内误触遮罩 | ESC / 遮罩关闭；表单不自动保存 |

## 十二、上线计划、依赖与上线后验证

**依赖**：数据域字典（域标签唯一）；模型列表（生效模型联动）；指标模块（termIds 读写）；权限中心（canAccessDomain）；文档中心（导入文件归档）。均为现有模块，无阻塞级外部依赖。

**上线计划（建议）**：① 灰度 1-2 个工程先开术语入口 → ② 收集首批挂载率/引用度 → ③ 全量放开并配套术语导入运营（按域批量导入首批词表）。

**上线后验证**：核心链路走查（创建→上线→字段推荐→挂载→指标引用→图谱→删除）；成功指标看板（字段挂载率、术语引用度）按周复盘。

## 十三、风险与遗留问题

| 编号 | 风险 | 概率 | 影响 | 等级 | 应对 |
|---|---|---|---|---|---|
| RK-01 | 覆盖导入误清空存量术语 | 中 | 高 | 高 | 预览页明示覆盖范围 + 二次确认 + 文件归档；后续增加覆盖前快照 |
| RK-02 | 确认即覆盖的重名策略被滥用 | 中 | 中 | 中 | 重名提醒列出命中域与名称；后续版本增加覆盖前差异对比 |
| RK-03 | 推荐命中过滥（描述相似度阈值偏低） | 中 | 低 | 低 | 忽略清单兜底；上线后按采纳率调阈值（0.45 为初始值，估算） |
| RK-04 | 无审批流导致术语质量参差 | 高 | 中 | 中 | 上线治理规范先行；审批流列入后续版本 |

**遗留问题**：活动信息流页签已预留未启用；词根同步仅入口；术语父子层级未支持（均列入后续版本）。

## 十四、附录

### 附录 A 界面结构
- **入口**：建模中心 → 定义语义 → 术语中心（与指标语义、文档中心、权限中心并列）。
- **布局**：左侧术语库列表（+ 添加）；库头部（名称/描述/创建人/创建时间/所属数据域 + 编辑入口）；页签「术语（计数）/ 关系图谱 /（活动信息流，暂隐藏）」。
- **术语列表列**：勾选、序号、术语名称（链接→详情）、数据域（筛选）、生效模型、同义词、术语描述、创建人、创建时间、上线状态（筛选）、操作（上线/下线、编辑、删除）。
- **工具栏**：搜索、下载模板、导出、导入、创建、批量操作（批量移动域/批量上下线/批量删除），仅「术语」页签显示。
